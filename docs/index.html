Everything you need, nothing you don't

Built for everyday remote work and helping family and friends.

Crisp picture

Full-color video (4:4:4 on NVIDIA GPUs) with correct colors — text looks like on the real screen, never washed out.

Low latency

Hardware video encoding on NVIDIA, Intel and AMD, and automatic adaptation to your connection.

Works anywhere

No port forwarding, no router setup. Both computers just need an internet connection.

End-to-end encrypted

Only the two computers can see the session — your screen, keystrokes and password stay private.

Unattended access

Runs as a Windows service: reach your PC after a restart, at the sign-in screen and through UAC — with Ctrl+Alt+Del.

File transfer

Drag & drop files onto the remote screen, or browse the remote computer's files and download with a click.

Shared clipboard

Copy text, images and even files on one computer and paste them on the other — Ctrl+C, Ctrl+V.

Multi-monitor

Switch between the remote computer's screens, view them fit-to-window or pixel-perfect 1:1.

No more washed-out screens

Many remote desktop tools blur colored text and lose contrast. KodDesk keeps full color detail and the exact color range.

Get started in a minute

Install on both computers, set a password, connect.

Install

Download the installer and run it on both computers.

Set a password

On the computer you want to reach, open KodDesk and set an access password.

Note the ID

Every computer gets a 9-digit ID, shown in the main window.

Connect

On the other computer, enter the ID and password — you're in.

The app's interface is currently in Romanian.

Private by design

Your computer, your data.

  • Every session is end-to-end encrypted and authenticated with the access password.
  • The password is never sent over the network and never stored in plain text.
  • Without the access password, nobody can connect to your computer.
  • On the controlled computer, files are accessed only with the permissions of the signed-in user.
  • Open source under the GPL-3.0 license — anyone can review the code.
